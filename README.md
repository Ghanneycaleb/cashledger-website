# CashLedger

A responsive financial services website built with HTML, CSS, and JavaScript.

## Features

- Responsive desktop and mobile layout
- Accessible hamburger navigation on mobile
- Lightbox gallery for business cases
- Blog and blog post pages
- Callback request form
- Font Awesome icons

## Technologies

- HTML5
- CSS3
- JavaScript
- jQuery
- Lightbox 2

## Run Locally

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Project Structure

- `index.html` provides the GitHub Pages entry point
- `home.html` contains the main CashLedger page
- `blog.html` and `post.html` contain the blog views
- `css/` contains stylesheets
- `js/` contains JavaScript files
- `images/` contains website assets

## Future Improvements

- Connect the callback form to a backend
- Replace placeholder copy with real content
- Add client-side form validation
- Improve image alternative text and accessibility coverage

## Deployment

This project can be hosted with GitHub Pages. After pushing the repository, select the `main` branch and the root folder under **Settings > Pages**.
